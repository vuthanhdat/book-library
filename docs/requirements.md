# Book Library Requirements

## Vision
A desktop-first personal knowledge reading platform.

## Core requirements
- Scan a configurable library root recursively.
- Detect PDF books and image-folder books.
- Initialize library by generating metadata, page count, cover thumbnail and SQLite records.
- Keep relative paths instead of absolute paths.
- Watch filesystem changes after initialization.
- Read PDF and image folders.
- Store notes in Markdown compatible with Obsidian.
- Maintain reading history, bookmarks and highlights.
- Phase 2: OCR, AI assistant, dictionary integration.
